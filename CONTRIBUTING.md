# Contributing

1. Create a focused branch from latest `main`.
2. Use clear commits and explain research rationale.
3. Open a pull request and request teammate review.
4. Do not merge until reviewed.

Research integrity: do not invent metrics, citations, labels, or dataset properties. Record provenance, license, modality, and split protocol. Preserve participant-wise separation and label hypotheses/preliminary/simulated results clearly.

Privacy and safety: never commit identifiable participant data, medical records, credentials, or unapproved recordings. Do not connect an experimental model to an occupied wheelchair.
