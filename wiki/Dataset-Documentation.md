# Dataset Documentation

Audit every dataset for source, license, modality, task, labels, participants, sessions, sampling rate/FPS, synchronization, and suitability.

Do not treat sensor-only tremor recordings as camera video or generic gesture datasets as tremor-labelled wheelchair command data. Keep raw identifiable data out of Git. See [dataset/README.md](../dataset/README.md) and [data collection draft](../dataset/data-collection.md).
