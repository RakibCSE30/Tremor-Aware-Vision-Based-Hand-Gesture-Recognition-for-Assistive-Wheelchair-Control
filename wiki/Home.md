# Project Wiki

Welcome to the documentation hub for **Tremor-Aware Vision-Based Hand Gesture Recognition for Assistive Wheelchair Control**.

This project explores camera-only temporal hand-gesture interpretation and conservative command generation under involuntary motion variability.
