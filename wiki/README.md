# GitHub Wiki Content

This directory contains Markdown source drafts for the project's Wiki. It is version-controlled with the repository so that documentation changes can be reviewed in pull requests.

To publish as actual GitHub Wiki pages, open the repository's **Wiki** tab, enable the Wiki if necessary, and create pages using the matching filenames/titles below. GitHub Wiki is a separate Git repository; these files do not automatically publish to the Wiki.
